# The outdoor gate as code

**Pattern 015 · Category: devops**

**Created: 2026-10-27T11:25:58Z**

> *“When handmade looks like agentic software development.”*

## Problem

Your outdoor gate needs renovation. Some sanding, fresh paint, and a few replacement parts should be enough. Unfortunately, managing such a project without version control would be irresponsible.

## Solution

Create a GitHub repository with a README, issues, milestones, and an `AGENTS.md` to define the project's conventions.

Document every defect, photograph the gate, and ask an AI agent to review the renovation plan. Track materials, dependencies, and progress through GitHub issues.

Naturally, every modification must be documented before implementation. Eventually, the project has a complete software development workflow. All that remains is the physical work.

## Benefits

- Every scratch has a GitHub issue.
- Paint colors become architectural decisions.
- AI agents can contribute without touching a tool.

## Success metric

More GitHub issues closed than screws replaced.

## The ultimate achievement

All the latest software engineering trends have been adopted. The renovation itself has been abandoned.
